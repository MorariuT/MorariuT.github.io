KMeans_

A closer look at the problem, the data flow, and the code.

~/overview

[ read ]

K-means groups points without class labels. It maintains a fixed number of cluster centers and alternates between assigning points to centers and moving each center to the average of its assigned points.

Things From ScratchPython / notebooks

~/how-it-works

[ walkthrough ]

initial centers → nearest-center assignment → cluster means → repeat

  1. Choose the number of clusters and initialize their centers.
  2. Measure each point’s distance to every center, then assign it to the nearest one.
  3. Replace each center with the mean of its assigned points.
  4. Repeat until the centers stop changing sufficiently or a fixed iteration budget is reached.

~/key-code-idea

[ python ]

Illustrative sketch. This is a shortened teaching example or pseudocode, not a complete runnable notebook or a verbatim source excerpt.

# Simplified NumPy assignment-and-update step.
distance_squared = ((points[:, None, :] - centers[None, :, :]) ** 2).sum(axis=2)
assignment = distance_squared.argmin(axis=1)
for cluster_id in range(len(centers)):
    members = points[assignment == cluster_id]
    if len(members):
        centers[cluster_id] = members.mean(axis=0)

Broadcasting creates one distance per point-center pair. Each row’s smallest entry determines the assignment. Updating the mean moves a center toward its members. Empty clusters need a separate policy; silently averaging an empty array would produce invalid values.

~/implementation-notes

[ inspect ]
  • The notebook initializes centers with integers between 0 and 3, independent of the data range. Choosing actual data points or k-means++ can make initialization more meaningful.
  • The fit method decrements self.iter directly. Reusing the same fitted object can therefore leave no iteration budget for another call.
  • Cluster numbers are arbitrary identifiers. Cluster 0 is not inherently the same as class 0 in a labeled demonstration.
