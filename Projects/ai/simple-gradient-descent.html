Simple Gradient Descent_

A closer look at the problem, the data flow, and the code.

~/overview

[ read ]

The simplest optimizer updates every parameter using a gradient calculated from the full training set. For linear regression, the prediction is a weighted sum of input features. The learning rate determines how far to move after each gradient calculation.

Things From ScratchPython / notebooks

~/how-it-works

[ walkthrough ]

all training rows → signed residuals → full-batch gradient → updated weights

  1. Initialize one weight per feature. Include a separate bias or a constant feature if an intercept is required.
  2. Compute predictions for every training row and subtract the target values.
  3. Multiply the residuals by the transposed feature matrix to accumulate each feature’s contribution.
  4. Update the weights and check a consistent objective. Use a maximum iteration count as well as any convergence criterion.

~/key-code-idea

[ python ]

Illustrative sketch. This is a shortened teaching example or pseudocode, not a complete runnable notebook or a verbatim source excerpt.

# Corrected reference for mean squared error, not a notebook excerpt.
for step in range(max_steps):
    residual = features @ weights - targets
    gradient = 2 * features.T @ residual / len(features)
    weights -= learning_rate * gradient

A feature contributes more to the update when it is large on rows with large signed errors. Standardizing feature scales can prevent a single feature from dominating the optimization. If the learning rate is too large, the updates can jump past a good solution and increase the loss.

~/implementation-notes

[ inspect ]
  • The notebook computes an absolute error and multiplies it by X.T. Removing the error sign changes the intended gradient direction.
  • Its example data comes from make_regression. A one-feature demonstration can hide mistakes that become visible with several features.
  • The loop uses an improvement threshold and a counter. Add a hard iteration limit when adapting the experiment so it cannot run indefinitely.
