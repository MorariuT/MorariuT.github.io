Weight Decay Gradient Descent_

A closer look at the problem, the data flow, and the code.

~/overview

[ read ]

A model can reduce training error by using large weights that react strongly to small input changes. L2 regularization adds a penalty for weight size. In ordinary gradient descent, its derivative creates a shrinkage term in the update.

Things From ScratchPython / notebooks

~/how-it-works

[ walkthrough ]

prediction loss + L2 penalty → combined gradient → smaller-weight update

  1. State the objective precisely, including the normalization of the prediction loss.
  2. Calculate the prediction-loss gradient.
  3. Add the derivative of the squared-weight penalty to the gradient.
  4. Tune the penalty strength using held-out data rather than expecting smaller weights to always be better.

~/key-code-idea

[ python ]

Illustrative sketch. This is a shortened teaching example or pseudocode, not a complete runnable notebook or a verbatim source excerpt.

# For loss = mean((X @ w - y)**2) + strength/2 * sum(w**2).
residual = features @ weights - targets
data_gradient = 2 * features.T @ residual / len(features)
penalty_gradient = strength * weights
weights -= learning_rate * (data_gradient + penalty_gradient)

The L2 term contributes strength times the weights. Subtracting that contribution pulls each weight toward zero while the data gradient tries to improve predictions. If a separate bias is used, it is often excluded from this penalty.

~/implementation-notes

[ inspect ]
  • The notebook adds a squared-weight expression to an absolute-error array, then multiplies by X.T. That is not the standard derivative of an L2-regularized MSE objective.
  • Feature scaling changes how strongly equal-sized weights influence predictions, so regularization and preprocessing need to be considered together.
  • Decoupled weight decay and an L2 penalty are not interchangeable for every adaptive optimizer. The example here is ordinary gradient descent.
