Word2Vec From Scratch_

A closer look at the problem, the data flow, and the code.

~/overview

[ read ]

Words begin as discrete symbols. An embedding gives each word a vector so that a model can learn relationships from surrounding text. This experiment constructs vocabulary vectors and trains a small projection network.

Things From ScratchPython / notebooks

~/how-it-works

[ walkthrough ]

text → vocabulary → context vectors → hidden representation → vocabulary-sized output

  1. Normalize the text and assign a stable integer index to every vocabulary item.
  2. Build training examples from nearby words. Decide whether the task predicts a center word from context or context from a center word.
  3. Project the vocabulary representation into a smaller hidden space.
  4. Train against a target that matches the selected objective, then inspect the learned representation separately from reconstruction quality.

~/key-code-idea

[ python ]

Illustrative sketch. This is a shortened teaching example or pseudocode, not a complete runnable notebook or a verbatim source excerpt.

# Conceptual center-word prediction from a bag of context words.
context_vector = make_context_vector(neighboring_words, vocabulary)
hidden_features = input_projection(context_vector)
center_word_logits = output_projection(hidden_features)
loss = cross_entropy(center_word_logits, center_word_id)

The first projection converts a high-dimensional vocabulary vector into hidden features. The second converts those features into vocabulary scores. The training target determines what the hidden space learns: predicting a missing center word is different from reconstructing a context vector.

~/implementation-notes

[ inspect ]
  • The notebook uses two linear layers named cbow and skip_gram and an MSE loss. Layer names alone do not establish either standard Word2Vec objective.
  • The inspected context loop includes offset zero, so the center token is present in the constructed input. Check that against the intended prediction target.
  • Its parameter named batch_size also controls the hidden layer width. Distinguish representation size from the number of examples processed in one update.

~/source

[ references ]

The notebook preprocesses a training_text file, builds vocabulary-indexed vectors, and defines a two-linear-layer PyTorch network. The sketch illustrates a clearly specified context-to-center objective instead of claiming that the experimental code implements it exactly.
