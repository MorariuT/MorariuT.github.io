Water Meter Segmentation_

A closer look at the problem, the data flow, and the code.

~/overview

[ read ]

Before reading a meter, it helps to locate the display containing the digits. This project treats that localization as segmentation: instead of assigning one label to the whole photo, the model identifies the pixels belonging to the target region.

Computer VisionPython / notebooks

~/how-it-works

[ walkthrough ]

meter photo → image preprocessing → U-Net → foreground mask → located digit region

  1. Pair every photo with the annotation describing its target region. Input and mask must refer to the same scene.
  2. Apply geometric transformations to the image and mask together. Resizing only the image would misalign the labels.
  3. Use an encoder to gather context and a decoder to recover spatial detail. U-Net skip connections carry information between corresponding resolutions.
  4. Turn the output into a mask and compare it with the annotation. A crop can then be passed to a separate OCR stage.

~/key-code-idea

[ python ]

Illustrative sketch. This is a shortened teaching example or pseudocode, not a complete runnable notebook or a verbatim source excerpt.

# Conceptual binary segmentation pipeline.
mask_logits = segmentation_model(images)
mask_probabilities = sigmoid(mask_logits)
foreground = mask_probabilities > threshold
intersection = (foreground & target_mask).sum()
union = (foreground | target_mask).sum()
iou = intersection / max(union, 1)

A probability map preserves uncertainty at each pixel. Thresholding creates the binary foreground region used for a crop or overlap calculation. Intersection over union measures how much the predicted and target regions overlap; it is more informative than counting the many easy background pixels.

~/implementation-notes

[ inspect ]
  • The segmentation stage locates the display; it does not by itself transcribe the number.
  • Use nearest-neighbor interpolation for categorical masks so that resizing does not invent intermediate class labels.
  • Inspect rotated meters, reflections, and small displays separately. A high average overlap can hide difficult cases.
