Vaccination Tweet Classification_

A closer look at the problem, the data flow, and the code.

~/overview

[ read ]

This project turns short, noisy social-media messages into numeric features and predicts their vaccination-related labels. The difficult part is preserving meaning while cleaning text: slang, repeated letters, and negation can change how a message should be interpreted.

Natural Language ProcessingPython / notebooks

~/how-it-works

[ walkthrough ]

tweet → text cleaning → TF-IDF features → classifier → class probabilities

  1. Load the labeled training messages and unlabeled test messages.
  2. Normalize text and expand slang where appropriate. Inspect examples after cleaning rather than assuming every rule helps.
  3. Fit a TF-IDF vocabulary on training text, then transform other messages using that same vocabulary.
  4. Train a classifier and produce probabilities. Keep the relationship between probability columns and class labels explicit.

~/key-code-idea

[ python ]

Illustrative sketch. This is a shortened teaching example or pseudocode, not a complete runnable notebook or a verbatim source excerpt.

# A compact example of the fitted-vocabulary pattern.
vectorizer = TfidfVectorizer()
training_features = vectorizer.fit_transform(training_messages)
validation_features = vectorizer.transform(validation_messages)
classifier.fit(training_features, training_labels)
probabilities = classifier.predict_proba(validation_features)

TF-IDF represents a message by weighted token frequencies. Fitting learns the vocabulary and weighting statistics; transforming reuses them. A word absent from the fitted vocabulary cannot gain a new feature simply because it appears in validation data.

~/implementation-notes

[ inspect ]
  • The notebook exports a score computed from the first and third probability columns. Verify the classifier’s class ordering before interpreting that score.
  • Some string replacement calls in the notebook do not assign their returned values. Python strings are immutable, so those calls alone do not update the original text.
  • Compare preprocessing variants using held-out labels. Removing short words or repeated characters can remove useful distinctions.

[ references ]
