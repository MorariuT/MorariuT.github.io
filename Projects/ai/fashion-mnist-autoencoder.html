From Scratch MNIST Autoencoder_

A closer look at the problem, the data flow, and the code.

~/overview

[ read ]

This experiment compresses Fashion-MNIST clothing images and reconstructs them. The target is the original image, so labels such as shirt or shoe are unnecessary for the reconstruction objective. A compact hidden vector must preserve enough information to produce recognizable pixels.

Computer VisionPython / notebooks

~/how-it-works

[ walkthrough ]

28 × 28 clothing image → 784 values → encoder → 8 features → decoder → reconstructed image

  1. Load Fashion-MNIST and scale pixel intensities into the 0–1 range.
  2. Flatten each 28 by 28 grayscale image into 784 values.
  3. Send the values through the encoder, reducing the representation to eight features.
  4. Decode those features and compare the resulting pixels with the original. Evaluate both familiar and held-out images.

~/key-code-idea

[ python ]

Illustrative sketch. This is a shortened teaching example or pseudocode, not a complete runnable notebook or a verbatim source excerpt.

# Simplified reconstruction objective.
flat_images = images.reshape(-1, 784)
latent = encoder(flat_images)
reconstruction = decoder(latent)
loss = ((reconstruction - flat_images) ** 2).mean()
loss.backward()

The loss is low when reconstructed pixels are close to the target pixels. It does not directly measure whether the hidden features correspond to useful clothing concepts. An eight-feature bottleneck makes compression visible: fine detail may disappear even when the overall shape survives.

~/implementation-notes

[ inspect ]
  • Despite the filename, the data loader uses Fashion-MNIST, not the handwritten-digit dataset.
  • A denoising objective needs corrupted inputs paired with clean targets. Reconstructing clean inputs alone is not sufficient evidence of a denoising model.
  • The inspected encoder is deterministic. A notebook heading saying VAE does not establish variational sampling or a KL penalty.
