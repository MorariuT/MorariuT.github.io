Hierarchical Clustering_

A closer look at the problem, the data flow, and the code.

~/overview

[ read ]

Agglomerative clustering starts with one cluster per point and repeatedly merges two clusters. Unlike k-means, it constructs a hierarchy. The distance rule between groups, called linkage, determines which merges happen first.

Things From ScratchPython / notebooks

~/how-it-works

[ walkthrough ]

singleton clusters → distinct cluster pairs → linkage distance → closest merge → repeat

  1. Assign every point its own cluster label.
  2. Compare only distinct pairs of clusters. A cluster must never be selected for merging with itself.
  3. Calculate a defined linkage distance, such as the minimum, maximum, or mean cross-cluster point distance.
  4. Merge the closest pair, update membership, and stop at the requested number of clusters.

~/key-code-idea

[ python ]

Illustrative sketch. This is a shortened teaching example or pseudocode, not a complete runnable notebook or a verbatim source excerpt.

# Conceptual average-linkage merge; membership stores point indices.
pairs = [(a, b) for a in range(len(groups))
         for b in range(a + 1, len(groups))]
a, b = min(pairs, key=lambda pair: average_linkage(
    points[groups[pair[0]]], points[groups[pair[1]]]
))
groups[a] = groups[a] + groups[b]
del groups[b]

Restricting b to indices greater than a avoids duplicate comparisons and self-comparisons. Average linkage should average cross-cluster distances; summing them without normalization changes how cluster size influences the decision. Recomputing pair distances after a merge is necessary because membership has changed.

~/implementation-notes

[ inspect ]
  • The catalog already marks this experiment as not quite working. Its inspected code compares clusters with themselves, which can select a non-merge.
  • The source accumulates cross-point distances without averaging. That is not standard average linkage.
  • The displayed relabeling block is inside the outer cluster-comparison loop. A correct implementation first finishes selecting the globally closest pair, then performs one merge.
